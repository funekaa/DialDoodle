# DialDoodle 🎯 - 旋转解密绘图盘生成器

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Pure Vanilla JS](https://img.shields.io/badge/Vanilla-ES6+-yellow.svg)]()
[![Platform: Web / MiniProgram](https://img.shields.io/badge/Platform-Web%20%7C%20WeChat-green.svg)]()

> **DialDoodle**（旋转涂鸦盘）是一个基于**极坐标几何逆变换**的益智解密绘图玩具生成程序。
> 用户提供或选择简笔画后，算法将其线条打散加密逆转分布在旋转圆盘（**B 纸**）上。
> 将 B 纸用图钉固定在底层的 **A 纸** 上旋转，对齐每个刻度描线，最后移开 B 纸，A 纸上就会奇迹般揭晓出原本完全看不出来的完整图案！

---

## 🎨 核心玩法与实物制作

1. **A 纸 (底部画纸 - 固定)**：
   - 固定在桌面上，正上方（12点钟方向）有一条醒目的红色**指示基准线**与圆心定位十字。
2. **B 纸 (生成的圆形画纸 - 旋转)**：
   - 一键打印到 A4 纸上，沿外圈虚线剪下大圆盘；
   - 用笔刀沿开槽线镂空缝隙（每个开槽旁附有微型刻度数字）；
   - 圆心穿入图钉。
3. **旋转描线**：
   - 将 B 纸用图钉钉在 A 纸中心，自由旋转；
   - 旋转 B 纸使刻度 **1** 对准 A 纸正上方指示线，找到开槽描线；
   - 旋转到刻度 **2** 对准指示线，沿露出的开槽描线……
   - 依次画完所有刻度（支持 10 ~ 20 个刻度精准调节）。
4. **惊喜揭秘**：
   - 移开 B 纸，A 纸上完美拼合出清晰生动的简笔画！

---

## 📐 算法原理 (Polar Coordinate Inverse Mapping)

1. **极坐标系定义**：
   - 圆盘圆心为原点 (0, 0)，A 纸正上方指示线方向为极轴基准 0°。
2. **逆旋转映射**：
   - 若刻度 k 位于圆周极角 θ_k（顺时针），当旋转 B 纸使该刻度对齐正上方指示线时，B 纸整体旋转了 -θ_k。
   - 该刻度对应的真实画作线段在 A 纸上的物理坐标为 (x_A, y_A)。
   - 穿过开槽落在 A 纸上的线条需严格满足：
     (x_B, y_B) = Rotate((x_A, y_A), +θ_k)
   - 复原验证：
     Rotate((x_B, y_B), -θ_k) = (x_A, y_A)
     位置与形态 100% 严丝合缝，零畸变！
3. **升级特性**：
   - **零丢线与零锁死 (Zero Line Drop)**：采用 `distributeStrokesToTicks` 智能均分分配，10 到 20 个刻度自由调节，所有线条细节 100% 完整保留；
   - **纯净切分与零自交 (Pure Subdivision & Zero Knot)**：彻底废除跨线条拼接合并，杜绝麻花结与自交叉；
   - **闭环与狭缝拆解 (1/2 对半或 1/3 均分)**：圆、椭圆与近闭合回路强制切成大开口弧线，防止纸心镂空脱落；
   - **坚固纸边与安全画幅**：外圈预留 ≥ 45px 坚固纸带，裁剪时绝不剪破开槽。

## 💻 快速上手

### 1. 本地运行 (开箱即用，无任何外部构建依赖)
- **Windows 用户**：双击 `start_web.bat` 即可自动启动本地服务并打开浏览器。
- **命令行**：
  ```bash
  python -m http.server 8000
  ```
  在浏览器访问：`http://localhost:8000`

### 2. GitHub Pages 一键在线访问
本项目为纯静态前端，可直接部署在 GitHub Pages：
1. 进入 GitHub 仓库设置 `Settings` -> `Pages`；
2. 在 `Build and deployment` 分支选择 `main`，目录选择 `/ (root)`；
3. 保存后即可通过：[https://funekaa.github.io/DialDoodle/](https://funekaa.github.io/DialDoodle/) 在线体验！

## 📱 微信小程序移植

核心数学与几何算法完全脱离 DOM，位于 `js/core/` 目录：
- `js/core/geometry.js`：几何运算、相交检测、外延徽标定位；
- `js/core/splitter.js`：打散与零相交排布求解器；
- `js/core/presets.js`：预设矢量图形库。

移植到小程序只需将渲染上下文替换为小程序的 `<canvas type="2d">` 即可。
